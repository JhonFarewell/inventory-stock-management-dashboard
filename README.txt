INVENTORY AND STOCK MANAGEMENT DASHBOARD

Project Description:
This project is a web-based Inventory and Stock Management Dashboard developed using Django. It provides a simple interface for managing inventory products and categories. The system includes user authentication, a dashboard displaying inventory statistics, product management, category management, and an administrator panel.

Features:
• User Login Authentication
• Dashboard displaying total products and total categories
• Product Management
• Category Management
• Django Administration Panel
• SQLite Database Integration

Technologies Used:
• Python
• Django (6.0.6)
• HTML
• CSS
• JavaScript
• SQLite

Project Structure:
inventory/              Django application
inventory_project/      Project configuration
templates/              HTML templates
static/                 CSS, JavaScript and images
db.sqlite3              Database
manage.py               Django management file

How to Run:
1. Open the project folder.
2. Open the terminal.
3. Run:

   py manage.py runserver

4. Open your browser and visit:

   http://127.0.0.1:8000/
